    Mulai Cepat

    1. Flash micro:bit dengan program MicroPython yang mengaktifkan bluetooth.UART() — lihat Contoh Kode.
    2. Buka halaman ini di Chrome / Edge lewat HTTPS atau localhost.
    3. Klik Hubungkan ke Micro:bit, pilih perangkatmu — data & kontrol langsung aktif.
    4. Tanpa perangkat? Klik Mode Demo. Pengaturan lengkap ada di menu Pengaturan.

    Fitur Sesi

    Alarm suhu

    Bunyi + kartu berdenyut merah saat suhu melewati ambang; berhenti sendiri saat suhu turun sedikit di bawahnya. Klik Uji bunyi sekali untuk cek suara.

    Rekaman & Export CSV

    Semua data otomatis terekam dengan stempel waktu. Klik Export CSV lalu buka di Excel / Google Sheets.

    Auto-reconnect & data basi

    Jika koneksi putus, panel menyambung ulang sendiri (aktifkan di sidebar). Data > 5 detik tanpa pembaruan ditandai BASI.

    Kipas otomatis

    Kecepatan kipas mengikuti suhu di antara dua ambang. Menggeser slider manual mematikannya.

    Statistik, gamepad & notifikasi

    Min / maks / rata-rata otomatis per sesi — praktis untuk laporan praktikum. Robot bisa dikendarai dengan gamepad USB; alarm tetap mengingatkan walau tab di latar.

    Contoh Kode

    Program MicroPython — salin & flash ke micro:bit 
    # micro:bit - MicroPython (cocok dengan panel ini)
# Flash lewat https://python.microbit.org lalu hubungkan dari panel ini
from microbit import *
import bluetooth

ble = bluetooth.BLE()
uart = bluetooth.UART()
buf = ""

def kirim(baris):
    uart.write(baris + "\n")

# Terima perintah dari Web
def tangani(cmd):
    if cmd == "lampu:1":
        pin0.write_digital(1)
        kirim("lampu:1")
        display.show(Image.YES)
    elif cmd == "lampu:0":
        pin0.write_digital(0)
        kirim("lampu:0")
        display.show(Image.NO)
    elif cmd.startswith("kipas:"):
        try:
            v = max(0, min(1023, int(cmd[6:])))
        except ValueError:
            v = 0
        pin1.write_analog(v)
        kirim("kipas:" + str(v))
    elif cmd == "atas":
        display.show(Image.ARROW_N)
    elif cmd == "bawah":
        display.show(Image.ARROW_S)
    elif cmd == "kiri":
        display.show(Image.ARROW_W)
    elif cmd == "kanan":
        display.show(Image.ARROW_E)
    elif cmd == "stop":
        display.clear()

while True:
    if uart.any():
        buf += str(uart.read(), "utf-8")
        while "\n" in buf:
            baris, buf = buf.split("\n", 1)
            if baris.strip():
                tangani(baris.strip())
    # Kirim data sensor ke Web tiap 1 detik
    kirim("suhu:" + str(temperature()))
    # micro:bit tidak punya sensor kelembaban bawaan -
    # ganti dengan sensor eksternal (mis. DHT11)
    kirim("kelembaban:60")
    kirim("mode:1")
    sleep(1000)

    Bantuan

    Tombol hubungkan error / tidak bisa diklik

    Gunakan Chrome/Edge terbaru, buka lewat HTTPS atau localhost, dan nyalakan Bluetooth.

    Perangkat tidak muncul

    Dekatkan micro:bit (< 2 m), pastikan program bluetooth.UART() sudah di-flash, dan tidak terhubung ke perangkat lain.

    Data tidak masuk

    Setiap baris harus berformat kunci:nilai dan diakhiri \n — persis seperti tabel Format Data.

    Sering putus / GATT error

    Matikan–nyalakan Bluetooth, lupakan perangkat micro:bit, sambungkan ulang, lalu aktifkan Auto-reconnect.

    Browser: Chrome / Edge / Opera didukung — Firefox & Safari belum (gunakan Mode Demo).

    Koneksi Bluetooth

    Auto-reconnect Sambung ulang otomatis jika putus tiba-tiba.
    Jaga layar menyala Cegah layar mati saat terhubung / demo (monitoring lama).
    Upaya maksimum 1–20 upaya sebelum berhenti.
    Prefiks nama perangkat Filter saat memilih perangkat.
    UUID service Berlaku untuk koneksi berikutnya. Karakteristik tetap terdeteksi otomatis.
